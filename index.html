Sinkronisasi Otomatis Google Sheet & Panduan Sistem

Setiap pendaftar baru atau perubahan status di panel admin akan otomatis dikirim ke Google Sheet Anda.

1. Kode Google Apps Script (Tempel di Extensions > Apps Script pada Google Sheet):

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Buat header otomatis jika baris masih kosong
  if (sheet.getLastRow() === 0) {
    sheet.appendRow([
      "No Pendaftaran", "Tanggal Daftar", "Nama Lengkap", "Tempat Lahir", 
      "Tanggal Lahir", "Umur", "Alamat", "Sekolah Asal", "Hobi", 
      "No HP Santri", "Nama Ayah", "Pekerjaan Ayah", "Nama Ibu", 
      "Pekerjaan Ibu", "No HP Ortu", "Status KK", "Status Akta", 
      "Status Foto", "Status Pendaftaran", "Petugas Penerima"
    ]);
  }
  
  sheet.appendRow([
    data.no_pendaftaran, data.tanggal_daftar, data.nama_lengkap, data.tempat_lahir,
    data.tanggal_lahir, data.umur, data.alamat_rumah, data.sekolah_asal, data.hobi,
    data.no_hp_santri, data.nama_ayah, data.pekerjaan_ayah, data.nama_ibu,
    data.pekerjaan_ibu, data.no_hp_ortu, data.status_kk, data.status_akta,
    data.status_foto, data.status, data.petugas_penerima
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}

2. Arsitektur Database & Keamanan Berkas (Produksi):

Untuk deployment server penuh (Node.js/Express + SQLite/PostgreSQL atau Laravel + MySQL):

  • Tabel pendaftar: id, no_pendaftaran (UNIQUE), nama_lengkap, tempat_lahir, tanggal_lahir, umur, alamat_rumah, sekolah_asal, hobi, no_hp_santri, status, petugas_penerima, created_at.
  • Tabel orang_tua: id, pendaftar_id (FK), nama_ayah, pekerjaan_ayah, nama_ibu, pekerjaan_ibu, no_hp_ortu.
  • Tabel berkas: id, pendaftar_id (FK), jenis_berkas (kk/akta/foto), uuid_filename, mime_type, status_verifikasi, catatan.
  • Tabel admin: id, username, password_hash (bcrypt/SHA-256).
  • Keamanan File: Simpan file di direktori privat /storage/private_docs/ (di luar public/) dengan nama UUID acak dan validasi magic-bytes MIME.
